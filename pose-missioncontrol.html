🚀 Quick Start Guide

📱 iOS Users: You must launch this page using the Bluefy app. Standard Safari or Chrome on iPhone/iPad does not support Web Bluetooth.

💻 Android/PC: Use Google Chrome for the best experience.

🤖 The Tech: This app uses Bluetooth UART (Serial) to talk to your micro:bit. It sends the name of your pose/image as a text string.

🔧 Setup: Use the Bluetooth UART extension in micro:bit to set this up!
